# 🎓 My English Tutor

Твой личный **AI-репетитор английского** — как Learna AI, но полностью **бесплатный** и **приватный**. Разговариваешь с репетитором, он объясняет, мягко исправляет ошибки, а слова сохраняются в словарь с карточками для повторения.

Работает в браузере, без регистрации и подписки. Все данные (переписка, словарь, прогресс) хранятся только у тебя в браузере.

## Что умеет

- 💬 **Чат с репетитором Lina** — живой разговор на английском, объяснения по-русски, если нужно.
- 🎙️ **Разговор голосом** — ты говоришь в микрофон, ИИ отвечает голосом. Есть режим «без рук» для непрерывной беседы.
- 🗣️ **Упражнения на произношение** — приложение показывает фразу, ты читаешь её вслух, а оно оценивает и подсвечивает слова (зелёным — верно, красным — нет).
- ✍️ **Разбор ошибок** — после твоего сообщения показывает исправленный вариант и объяснение.
- 🎭 **Сценарии** — свободный разговор, кафе, аэропорт, собеседование, магазин, у врача и т.д.
- 🎚️ **Уровни** — Beginner / Intermediate / Advanced (репетитор подстраивает сложность).
- 📚 **Словарь с карточками** — сохраняй слова, повторяй по системе интервального повторения (Лейтнер).
- 🔊 **Озвучка** — произношение слов и фраз голосом браузера.
- 📈 **Прогресс** — серия дней (streak), количество сообщений, выученные слова, график активности.

## Быстрый старт

### Шаг 1. Скачай проект

```bash
git clone <адрес-репозитория>
cd English
```

### Шаг 2. Выбери «мозг» — вариант A (локально, полностью бесплатно) или B (облако)

#### Вариант A — Ollama (рекомендую, работает офлайн и бесплатно)

1. Установи Ollama с [ollama.com](https://ollama.com) (Windows / macOS / Linux).
2. Скачай модель (в терминале):
   ```bash
   ollama pull llama3.2
   ```
   > Можно взять другую модель, например `qwen2.5` или `gemma2` — она лучше понимает языки. Тогда впиши её имя в ⚙️ Настройках.
3. Ollama запускается сам в фоне. Проверить: открой в браузере `http://localhost:11434` — должно быть «Ollama is running».

#### Вариант B — бесплатный облачный API (если комп слабый)

- **Groq** — быстро и бесплатно: зарегистрируйся на [console.groq.com](https://console.groq.com), создай API-ключ.
  - Base URL: `https://api.groq.com/openai/v1`
  - Модель: `llama-3.3-70b-versatile`
- **Google Gemini** — [aistudio.google.com](https://aistudio.google.com), создай ключ.
  - Base URL: `https://generativelanguage.googleapis.com/v1beta/openai`
  - Модель: `gemini-1.5-flash`

Ключ вводится в приложении (⚙️ Настройки → «Облачный API») и хранится только у тебя в браузере.

### Шаг 3. Запусти приложение

Проще всего — локальный веб-сервер (нужен для стабильной работы Ollama):

```bash
# Python (есть почти везде)
python -m http.server 5173
```

Затем открой в браузере **http://localhost:5173**

> Можно просто дважды кликнуть по `index.html`, но при работе с Ollama лучше через локальный сервер — иначе браузер может заблокировать запросы.

### Шаг 4. Настрой и общайся

1. Нажми ⚙️ вверху справа.
2. Выбери провайдера (Ollama или облачный API), проверь адрес/модель, нажми **«Проверить связь»**.
3. Сохрани и начинай писать репетитору! 🎉

## Если Ollama не подключается (CORS)

Браузер может блокировать запросы к Ollama из-за настроек безопасности. Разреши доступ, задав переменную окружения перед запуском Ollama:

- **macOS / Linux:**
  ```bash
  OLLAMA_ORIGINS='*' ollama serve
  ```
- **Windows (PowerShell):**
  ```powershell
  $env:OLLAMA_ORIGINS='*'; ollama serve
  ```

> `*` разрешает доступ с любого адреса. Для личного использования на своём компьютере это безопасно.

## Голосовые функции

Распознавание речи (микрофон) и озвучка работают на встроенном в браузер **Web Speech API** — бесплатно и без ключей.

- ✅ Лучше всего работает в **Google Chrome** и **Microsoft Edge** на компьютере.
- ⚠️ В Firefox распознавание речи не поддерживается (озвучка работает).
- 🔒 Для доступа к микрофону браузер один раз спросит разрешение — нажми «Разрешить».
- 🌐 Распознавание речи в Chrome использует онлайн-сервис Google, поэтому для голосовых режимов нужен интернет (сам чат при этом может работать локально через Ollama).

## Приватность

Всё работает локально. Переписка, словарь и прогресс не уходят никуда, кроме выбранной тобой модели. С Ollama данные вообще не покидают твой компьютер.
